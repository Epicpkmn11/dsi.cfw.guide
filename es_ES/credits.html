# Créditos

Estos son los créditos para aquellos que han ayudado con el sitio web de la guía, homebrew y otras cosas.

Si te gusta lo que han hecho, considera la posibilidad de donar (si tienen un enlace de donación).

  • NightScript (opens new window), Pk11 (opens new window) & Peter0x44 (opens new window): Mantenimiento de la guía
  • YourKalamity (opens new window): Creador de Lazy DSi File Downloader
  • emiyl (opens new window): Dueño del dominio
  • Halvorsen: Proporcionó una imagen de su Nintendo DSi para usar en la página de inicio
  • shutterbug2000 (opens new window): Descubridor & Desarrollador de camara DSi & Exploits de Flipnote Studio
  • WinterMute (opens new window): Mantenimiento del conjunto de herramientas para el desarrollo de Homebrew para DS, y la división del exploit de Flipnote Studio de ugopwn para crear Flipnote Lenny (que soporta todas las regiones y versiones de firmware).
  • nocash (opens new window): Desarrollador de Unlaunch.
  • RocketRobz (opens new window): Desarrollador de TWiLight Menu ++, hiyaCFW, y GodMode9i
  • zoogie (opens new window): Desarrollador de dumpTool y la división de Memory Pit que soporta todas las regiones y versiones de firmware.
  • Plailect (opens new window): Hizo la guía original de modifiación de 3DS, de la cual ésta guía tomó inspiración.

¡Puedes contribuir a nuestra guía simplemente enviando una pull request en github (opens new window)!

Si conoces otros idiomas, puedes ayudarnos traduciendo la guía a ese idioma. Puede unirse a nuestro Proyecto en Crowdin (opens new window) para empezar.
